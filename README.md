# Japanese Travel Phrases - PWA Installation Guide

Your flashcard app is now a Progressive Web App (PWA)! This means it can be installed on your phone like a native app and works offline.

## Files Included:
- `japanese-flashcards.html` - Main app file
- `manifest.json` - App configuration
- `service-worker.js` - Enables offline functionality
- `icon-192.png` - App icon (small)
- `icon-512.png` - App icon (large)

## How to Install on Your Phone:

### Step 1: Upload to Web Hosting
You need to host these files online. Here are the easiest free options:

**Option A: GitHub Pages (Recommended)**
1. Go to github.com and create a free account
2. Create a new repository (e.g., "japanese-flashcards")
3. Upload ALL 5 files to the repository
4. Go to Settings → Pages → Enable GitHub Pages
5. Your app will be at: `https://yourusername.github.io/japanese-flashcards/japanese-flashcards.html`

**Option B: Netlify (Easiest)**
1. Go to netlify.com and sign up (free)
2. Drag and drop all 5 files into Netlify
3. Get instant URL like: `https://your-site-name.netlify.app/japanese-flashcards.html`

### Step 2: Install on Phone

**iPhone:**
1. Open the URL in Safari browser
2. Tap the Share button (box with arrow)
3. Scroll down and tap "Add to Home Screen"
4. Tap "Add"
5. The app icon appears on your home screen!

**Android:**
1. Open the URL in Chrome browser
2. Tap the menu (3 dots in top right)
3. Tap "Add to Home Screen" or "Install app"
4. Tap "Install"
5. The app icon appears on your home screen!

### Step 3: Use Offline
Once installed, the app works completely offline! No internet required for practicing.

## Benefits of PWA:
✅ Works offline after first load
✅ Installs like a native app
✅ No app store required
✅ Updates automatically
✅ Fast and lightweight

## Troubleshooting:
- **"Add to Home Screen" not showing?** Make sure you're using HTTPS (hosting required)
- **Icons not showing?** Check that all 5 files are in the same folder
- **Offline not working?** Reload the page once after installation

## Quick Test:
1. Host the files
2. Visit the URL on your phone
3. Install to home screen
4. Turn off WiFi/data
5. Open the app - it should still work!
